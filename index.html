Projetos

Quatro projetos de firmware e drivers, cada um com o repositório original no GitHub. Os diagramas são esquemas simplificados feitos para este portfólio.

NS Monitor

Firmware para ESP32 que monitora o SLA de uma rede, com auditoria contínua de conectividade e análise de disponibilidade.

Usa FreeRTOS para dividir o trabalho em tarefas: a pilha de rede (LwIP), as requisições ICMP em segundo plano e a comunicação MQTT rodam sem bloquear o fluxo principal. Uma máquina de estados finita (FSM) controla a conectividade e permite recuperação automática com NVS.

  • C
  • ESP-IDF
  • FreeRTOS
  • MQTT
  • ESP32
Ver repositório do NS Monitor no GitHub (abre em nova aba)

ROM Structure Analysis

Engenharia reversa de uma ROM de 16 bits extraída de um teclado Casio.

Um leitor customizado em ESP32 faz o dump da ROM via GPIO. Para contornar a falta de pinos, o barramento de endereços é dividido: A[0–11] são controlados pelo firmware e A[12–17] ficam fixos no hardware. Um pipeline em Python reconstrói palavras de 16 bits a partir de MSB/LSB, converte CSV em BIN e gera visualizações dos padrões, identificando segmentos de forma de onda consistentes com síntese baseada em amostras.

  • C
  • Python
  • ESP32
  • ESP-IDF
  • Engenharia reversa
Ver repositório do ROM Structure Analysis no GitHub (abre em nova aba)

MPU-6050 Gyroscope Driver

Driver bare metal para o sensor MPU-6050 no RP2040, sem abstrações de SDK.

Acessa diretamente os registradores mapeados em memória do periférico I2C0, usando ponteiros volatile. A comunicação é em Fast Mode (400 kHz), com Burst Read para capturar os 3 eixos de forma sincronizada em uma única transação. O driver monitora a flag RFNE do registrador IC_STATUS e não usa interrupções nem DMA.

  • C
  • RP2040
  • I2C
  • Bare Metal
Ver repositório do MPU-6050 Gyroscope Driver no GitHub (abre em nova aba)

RP2040 ADC Temperature HAL

HAL bare metal para o ADC interno do RP2040, para medir a temperatura do MCU sem depender de SDKs externos.

A aquisição é feita por manipulação direta de registradores. O cálculo usa aritmética de ponto fixo em milli-Celsius (25000 = 25 °C), evitando operações de ponto flutuante. A inicialização fica separada da aquisição, o que facilita a integração em outros projetos.

  • RP2040

# Portfólio de Ruan Santos

Site pessoal de portfólio focado em sistemas embarcados, firmware e programação de baixo nível. Trabalho da disciplina de Interface Homem-Máquina, do curso de Tecnologia em Análise e Desenvolvimento de Sistemas (IF Baiano, Campus Guanambi).

## Descrição

Página única com as seções Início, Sobre mim, Habilidades técnicas, Projetos e Contato.

Os projetos apresentados são NS Monitor, ROM Structure Analysis, MPU-6050 Gyroscope Driver e RP2040 ADC Temperature HAL. Cada um tem descrição, tecnologias usadas e link para o repositório no GitHub.

## Tecnologias usadas

- HTML5 semântico
- CSS3: Grid, Flexbox, variáveis CSS, media queries e transições
- Sem JavaScript, frameworks ou bibliotecas
- Imagens locais em SVG, sem links externos

## Formulário de contato

O formulário tem validação nativa do HTML (`required`, `type="email"`, `minlength`) e usa `:user-invalid` para destacar o campo inválido.

O envio é feito com `mailto:`: ao enviar, o programa de e-mail do visitante abre com a mensagem pronta. O site não recebe mensagens sozinho, porque não há serviço de envio configurado.
